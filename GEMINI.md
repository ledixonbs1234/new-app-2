
# GEMINI.md

## Project Overview

This is a Chrome Extension project named "Realtime Portal".

The extension is built using **React** and **TypeScript**. It uses **Webpack** for bundling and **TailwindCSS** for styling. It also integrates with **Firebase** for real-time data synchronization.

The extension appears to be designed to interact with various services of Vietnam Post (`vnpost.vn`), including their CMS, customer portal, and internal services. It includes a popup interface, a background service worker, and several content scripts tailored for specific `vnpost.vn` subdomains.

## Building and Running

### 1. Install Dependencies

To install the necessary dependencies, run the following command in your terminal:

```bash
npm install
```

### 2. Development

To build the extension for development with live reloading, use the following command:

```bash
npm run dev
```

This will create a `dist` directory with the unpacked extension.

### 3. Production Build

To create a production-ready build of the extension, run:

```bash
npm run build
```

This will also create/update the `dist` directory.

### 4. Loading the Extension in Chrome

1.  Open Google Chrome and navigate to `chrome://extensions`.
2.  Enable "Developer mode" in the top right corner.
3.  Click on "Load unpacked".
4.  Select the `dist` directory generated by the build process.

## Development Conventions

*   **TypeScript:** The project uses TypeScript for static typing, which helps in maintaining code quality and catching errors early.
*   **Styling:** Styling is done using **TailwindCSS**. Configuration for TailwindCSS can be found in `tailwind.config.js` and `postcss.config.js`.
*   **Project Structure:** The source code is located in the `src` directory and is organized into the following components:
    *   `popup`: Contains the code for the extension's popup UI.
    *   `background`: Contains the background service worker logic.
    *   `contentScript`: Contains scripts that are injected into and interact with web pages.
    *   `offscreen`: Contains code for running in an offscreen document.
    *   `static`: Contains static assets like the `manifest.json`, icons, and other resources.
